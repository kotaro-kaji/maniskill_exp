解釈

current stage_return4x と 66de62b stable baseline は、どちらも eval_return_mean が80台で、終端成功率は160 envすべてで成功だった。 66de62b stable baseline は final_open_mean が最も強い。drawer を大きく、安定に開けるという意味では 依然として最良の基準点に見える。

current stage_return4x は final_return_arm_score が最も高い。 つまり、return の arm 関節状態だけを見るとこの条件が最も戻れている。 以前の eval_return_mean=48.471237 は、RunPod側の評価コード同期前に出した値で、 stage_return_reward の係数が古い状態だったため低く出ていた可能性が高い。 同期後に同じ checkpoint を再評価した結果が、この表の 81.434448 である。

10853ba initial 12cm は「一度は開く」能力はあるが、終端で開状態を維持する安定性が弱い。 このため、安定基準としては66de62bの方が明確に良い。

注意: ここでの66de62bは、現在branch上に復元した MyDualCardboardCabinet66de62b-v1 と既存15M checkpointの評価である。 旧 worktree の短め sweep checkpoint も残っているが、安定基準として扱っているのはこの復元15M runである。
