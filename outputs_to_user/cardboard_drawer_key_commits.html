1. 12cm 成功条件の初出: 10853ba

10853ba は、drawer return task が成立した最初の重要コミットである。 このコミットで tasks/dual/task_dual_cardboard_cabinet.py が tasks/single/task_single_cardboard_cabinet.py へ rename されつつ、 drawer open と return を含む single-arm task に大きく作り替えられた。

このコミットで入った成功条件

INNER_BOX_OPEN_GOAL_DISTANCE = 0.12
OUTER_BOX_STABLE_DISTANCE = 0.02

def _inner_box_open_enough(self):
    return self._inner_box_open_amount() >= self.INNER_BOX_OPEN_GOAL_DISTANCE

drawer_open_success = open_enough & outer_box_stable_enough

つまり、drawer open の条件は「inner box が 12cm 以上開く」かつ 「outer box shift が 2cm 以下」である。さらにタスク全体の success には return pose 条件も入っていた。

10853ba の 15M 学習確認

RunPod で 15M timestep まで同条件で学習させたところ、open 自体は壊れなかった。 ただし、後述の 66de62b より scalar は弱く、右 finger の小さな接触も混じった。

66de62b の報酬

reaching_reward = 0.5 * (
    1 - tanh(5.0 * tcp_to_target_distance)
    + 1 - tanh(30.0 * tcp_to_target_distance)
)

open_reward = 2.0 * inner_box_open_fraction * outer_box_stability

if open_amount >= 0.005:
    reaching_reward = 2.0

if open_enough:
    open_reward = 3.0

if drawer_open_success_reached:
    stage_return_reward = 4.0 + 4.0 * return_to_target_qpos_reward

reward = outer_box_stability * reward
normalized_reward = reward / (8.0 + 0.05)

66de62b の return target は arm 7 joints + gripper 6 joints の 13 次元で、 return score は arm 0.75 / gripper 0.25 の重みで計算されていた。

現時点の基準判断は、10853ba は初出として重要、66de62b は安定基準として重要、 という整理でよい。ただし旧 probe の stable 指標は不十分なので、今後の比較は 160 env 評価で eval_return_mean、final_open_success、 final_return_arm_score を確認する。

現在の評価方針

旧評価では途中最大 open amount を見ていたため、動画上の失敗や終端で閉じている挙動を過大評価した。 今後は eval_scripts/eval_cardboard_policy_metrics.py を使い、160 parallel env で以下を確認する。

  • eval_return_mean / eval_return_std
  • reached_open_success_mean: 途中で一度 12cm 以上開いた割合
  • final_open_success_mean: 終端時点で 12cm 以上開いている割合
  • final_return_arm_score_mean: 終端時点の arm return score
  • final_return_arm_mean_abs_error_mean と final_return_arm_max_abs_error_mean
